# Excel Sales Dashboard

## Project Overview
This project presents an interactive sales analysis and dashboard built using Microsoft Excel. It transforms sales data into meaningful business insights through KPI summaries, category analysis, regional performance analysis, and monthly sales trends.

## Tools Used
- Microsoft Excel
- PivotTables and PivotCharts
- Excel formulas and KPI calculations
- Slicers and data visualization
- Number formatting and dashboard design

## Key Performance Indicators
- Total Sales: $8,951,931.32
- Total Orders: 9,426
- Total Profit: $1,312,442.40
- Average Discount: 5%

## Key Insights
- Technology generated the highest sales, at approximately $3.51 million.
- The Central region recorded the highest sales, at approximately $2.54 million.
- Technology contributed the highest category profit, at approximately $683,098.
- November was the strongest sales month, with approximately $1.43 million in sales.

## Dashboard Features
- KPI cards for key business metrics
- Sales by Category
- Sales by Region
- Profit by Category
- Monthly Sales Trend
- Interactive slicers for filtering

## Project Files
- `Excel_Sales_Dashboard.xlsx` — Excel workbook containing the analysis and dashboard.
- `dashboard-screenshot.png` — Preview of the completed dashboard.

## Purpose
The objective of this project is to demonstrate practical Excel skills in data analysis, business reporting, KPI tracking, and dashboard development.
